# 📝 01Blog – Social Learning Platform

01Blog is a fullstack social blogging platform where students can share their learning journey, interact with others, and engage in a collaborative environment.

Built with **Spring Boot** and **Angular**, the application provides a secure and scalable system for content creation, user interaction, and moderation.

---

## 📌 Overview

01Blog allows users to:

- Share posts with text, images, or videos
- Follow other users and view their content
- Like and comment on posts
- Receive notifications from subscriptions
- Report inappropriate content

Admins have full moderation capabilities to ensure a safe and respectful platform.

---

## 🧩 Architecture

This project follows a **fullstack architecture**:

- **Frontend:** Angular (SPA)
- **Backend:** Spring Boot (REST API)
- **Database:** PostgreSQL / MySQL
- **Authentication:** JWT + Spring Security

---

## ✨ Features

### 👤 User Features

- 🔐 Secure authentication (JWT)
- 📝 Create, edit, delete posts
- 🖼 Upload images/videos with preview
- ❤️ Like and comment on posts
- 🔔 Receive notifications from subscriptions
- 👥 Follow / unfollow users
- 🚩 Report users or content

### 🛠 Admin Features

- 👥 Manage users (ban/delete)
- 📝 Moderate posts
- 🚨 View and handle reports
- 🔒 Role-based access control
